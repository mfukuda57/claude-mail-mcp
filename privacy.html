Privacy Policy

Last updated: 2026-10-01

Claude Mail MCP (personal) is a private tool used only by its developer with the developer's own Google accounts.

  • Data accessed: Gmail, Google Calendar and Google Drive data, read-only, via Google OAuth scopes granted by the account owner.
  • Use: The data is read on the owner's own computer only to answer the owner's requests to their AI assistant.
  • Storage: OAuth tokens are stored locally on the owner's computer. No data is stored on any server operated by this app.
  • Sharing: Data is not sold, shared with third parties, or used for advertising.
  • Revocation: Access can be revoked at any time at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
